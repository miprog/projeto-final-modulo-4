# Projeto Final - Modulo 4 - Full Cycle

**Nivel: Projeto B - Nivel Simples**
**Aluna: Milena Barros**

## O que e
Sistema de Pedidos refatorado com calculo de total e desconto por estrategia.

## Regra de negocio
- ItemPedido tem preco (p) e quantidade (q)
- DescontoComum: sem desconto
- DescontoVip: 10% de desconto
- DescontoFuncionario: 30% de desconto

## Como rodar
npm install
npm test

## Como reaproveitei
Reaproveitei o projeto de refatoracao de pedidos (pedido.ts + pedido.test.ts). O projeto final consolida, nao recomeca.
